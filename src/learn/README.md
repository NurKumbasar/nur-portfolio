# Alıştırma Alanı

Bu klasör gerçek site kodu **değil**. Burası senin pratik yapman için.
Her ders bir dosya çifti: `NN-konu.ts` (senin dolduracağın) ve
`NN-konu.test.ts` (kontrol eden test — dokunmana gerek yok).

Nasıl çalışıyor:
1. `NN-konu.ts` içindeki `// TODO` yazan yeri doldur.
2. Terminalde `npm test` çalıştır (veya bana "yazdım" de, ben çalıştırırım).
3. Test yeşil (PASS) olursa doğru yapmışsın demektir, kırmızıysa (FAIL)
   hata mesajı sana ne beklenip ne geldiğini gösterir.
